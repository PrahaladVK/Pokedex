# @pokedex/data

Versioned Pokémon data, generated by `pnpm sync:pokeapi` (see `/scripts/sync-pokeapi.ts`) and hand-curated afterwards.

- `manifest.json`: lists every generation pack and its data/schema version.
- `generations/genN.json` / `generations/legends-za.json`: one pack per generation.
- `game-versions.json`: registry of every mainline game, grouped into version groups.
- `overrides/`: optional hand-written corrections layered on top of synced data (see `scripts/sync-pokeapi.ts`).

Do not hand-edit synced fields directly unless you also intend to re-run the sync and reconcile them; prefer adding an override instead. Purely manual packs (like `legends-za` while `status` is `"partial"`) are fine to edit directly.
